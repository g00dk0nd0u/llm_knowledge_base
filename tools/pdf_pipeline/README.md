# PDF Pipeline

Reserved for the reproducible PDF-to-knowledge processing pipeline.

Planned responsibilities:

1. detect newly added PDFs;
2. compute source hashes;
3. extract text and document structure;
4. preserve page boundaries and source mappings;
5. generate LLM-searchable Markdown;
6. update project manifests/indexes;
7. optionally render selected pages/regions for vision use.

The implementation is intentionally deferred until the repository structure is validated with real PDFs.
